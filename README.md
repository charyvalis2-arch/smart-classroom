# 🏫 翠屏老師的國文課

單頁式課堂經營工具箱，純前端（HTML / CSS / JavaScript），不需安裝、不需後端，放到 GitHub Pages 就能用。

## 功能（11 個分頁）

| 分頁 | 功能 |
|---|---|
| 🎯 隨機抽籤 | 拉霸動畫、重複／不重複抽籤、未抽／已抽統計、抽籤歷程、重設抽籤池 |
| 🏆 小組計分板 | 新增／刪除／改名組別、±1 計分、歸零、自動儲存（可同步雲端） |
| ⏱️ 課堂計時器 | 圓形進度條、開始／暫停／重設、快速預設、自訂分秒、時間到叮咚音、最後 10 秒紅色警示 |
| 🎲 隨機分組器 | 依「組數」或「每組人數」隨機分組 |
| 🧩 異質性分組工作表 | 拖曳／點選排位、6 個可編輯職務、Excel/CSV 匯入、全班與各組計分、榮譽證書、班級公約、A4 列印 |
| 🎵 互動音效板 | 6 種課堂音效（瀏覽器合成） |
| 🔊 趣味音量計 | 麥克風監測、泡泡破裂、門檻／敏感度、噓聲提示、紅光警示 |
| 📊 段考成績單 | 全班成績輸入、個人 vs 班平均圖表、A4 個別／批次列印 |
| 🧹 打掃輪值 | 匯入名單、自動分配區域、一鍵輪替、每日打卡、A4 列印輪值表 |
| 🟥 紅單開立通知 | 貼上座號/姓名或匯入 Excel/CSV，自動產生紅單，A4 一頁四張列印 |
| ⚙️ 雲端與名單設定 | 全站共用學生名單、Google Apps Script 雲端同步（選用） |

## 使用
直接開啟 `index.html`，或用 GitHub Pages 發布。資料預設存在瀏覽器（localStorage）。

## 雲端同步（選用）
1. 到 <https://script.google.com> 新增專案，貼上 `gas/Code.gs`
2. 部署 → 網頁應用程式 → 執行身分「我」、存取權「所有人」
3. 把 `/exec` 網址貼到網站「雲端與名單設定」→ 儲存 → 測試連線

## 檔案
```
index.html   頁面結構
style.css    樣式
app.js       主要邏輯
extra.js     打掃輪值、紅單開立通知
gas/Code.gs  Google Apps Script 後端（選用）
```


## 新版重點（打掃／紅單／班級／計時器）
- **多班級**：預設 711、712、713 三班（可改名、新增），名單、抽籤紀錄、異質性分組、成績單、打掃、紅單累計都依班級分開儲存；各分頁上方有班級選單。
- **小組計分板**預設六組。
- **課堂計時器**：開始時把「靜音＋結尾鈴聲」排進 `<audio>`，並保持螢幕不休眠；iPad 切到別的 App 或螢幕移開時仍會響鈴。有「測試鈴聲」。
- **打掃輪值**：內掃區／外掃區各為一個區塊（可新增、複製、刪除、輪替負責人）；行事曆選週、按週 O／X 打卡、列印；Word 下載區（本週、全部區塊、空白表）與 CSV。負責人以座號記錄，姓名只在瀏覽器依名單對照。
- **紅單**：導師紅單（校園生活、學習狀況通知單，五張一支警告自動累計）與任課老師紅單（國文作業通知單）；輸入座號／姓名自動產生，可列印或下載 Word。
- `vendor/docx.js`：產生 Word 用的函式庫（docx 8.5.0，MIT 授權），離線也能用。
